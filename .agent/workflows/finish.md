# 여기엔 STT 타이퍼 - 작업 마무리 워크플로우

## 1. 세션 로그 작성
`docs/session_logs/YYYY-MM-DD_work_log.md` 파일 생성

### 포함 내용
- 오늘 작업 요약 (카테고리별)
- 변경된 파일 목록
- 향후 주의사항
- 미해결 과제

### 세션 로그 템플릿
```markdown
# YYYY-MM-DD 작업 로그

## 작업 요약
- (오늘 수행한 작업 개요)

## 완료된 작업
- (구현된 기능 또는 수정 사항)

## 변경된 파일
- (변경된 파일 목록)

## 주의사항
- (향후 작업 시 참고할 사항)

## 미해결 과제
- (남은 작업 또는 이슈)
```

## 2. Git 상태 확인
// turbo
```bash
git status
```

## 3. Git 커밋
사용자에게 아래 형식으로 커밋 메시지를 제시하고, 승인 후 실행한다.
```bash
git add -A && git commit -m "[타입] 작업 요약"
```

### 커밋 메시지 타입 (한글)
- `[기능]` - 새로운 기능 추가
- `[수정]` - 버그 수정
- `[리팩토링]` - 코드 구조 개선
- `[문서]` - 문서 추가/수정
- `[설정]` - 설정 파일 변경

### 주의사항
- 원격 레포가 없으므로 Push는 하지 않는다.
- 커밋 메시지는 반드시 한글로 작성한다.
- google_credentials.json, whisperer_settings.json 등 민감 파일이 포함되지 않았는지 확인한다.

## 4. 마무리 메시지
작업 완료 요약을 사용자에게 출력한다:
- 오늘 완료한 작업 목록
- 커밋된 변경사항
- 남은 작업 또는 다음 단계 안내

---

**참고:** 이 워크플로우는 `/finish` 명령으로 실행한다.
