# BluemingReadAloud

Google Cloud Text-to-Speech로 **선택한 글을 소리 내어 읽어 주는** 윈도우 트레이 앱입니다.
어느 프로그램에서든 글을 드래그해 선택하면 선택 끝 옆에 **빨간 점**이 뜹니다. 점을 누르거나 단축키를 누르면 읽어 줍니다.

## 주요 기능

- **선택한 글 읽어주기**: 글을 선택하고 단축키(기본 `Ctrl + Alt + D`)를 누르면 읽습니다.
  읽기 전에 마크다운 기호·URL·특수문자를 정리하고, 긴 글은 조각으로 나눠 끊김 없이 이어서 재생합니다.
- **빨간 점 (선택한 글 읽기 버튼)**: 크롬 확장처럼, 글을 **드래그하거나 더블클릭**해서 고르면 마우스를 뗀 자리 옆에
  작은 빨간 점이 뜹니다. 누르면 선택한 글을 읽습니다.
  - 다른 곳을 클릭하거나, 키를 누르거나, 휠을 굴리면 사라집니다.
  - 점을 눌러도 글을 고른 창의 포커스·선택은 그대로 남습니다.
  - 윈도우는 다른 프로그램의 "글이 선택됨"을 알려 주지 않아서, 마우스 동작으로 짐작해 띄웁니다.
    그래서 창 제목 막대를 끌 때도 뜰 수 있고(누르면 단축키와 같습니다 — 그 창에 골라 둔 글이 남아 있으면 읽고,
    없으면 아무 일도 없습니다), 키보드(Shift+화살표)로 고른 글에는 뜨지 않습니다
    (이때는 단축키를 쓰세요).
  - 화면 오른쪽 끝처럼 점을 오른쪽에 둘 자리가 없으면 마우스 왼쪽에 뜹니다(마우스 바로 밑에는 뜨지 않습니다).
  - 트레이 메뉴 **텍스트 선택 시 읽기 버튼**으로 끄고 켤 수 있습니다(기본 켬).
- **단축키 하나로 세 가지 동작**
  - 글이 선택돼 있으면 → 읽기 (읽는 중이어도 새로 선택한 글로 바꿔 읽음)
  - 읽는 중인데 선택된 글이 없으면 → 중지
  - 읽고 있지 않은데 선택된 글도 없으면 → 아무것도 하지 않음
- **하단 재생 컨트롤러**: 읽는 동안 화면 아래에 재생 바가 뜹니다(일시정지·이전/다음 단락·음소거·속도·볼륨·중지).
- **원문 위 형광펜**: 읽는 동안 글을 고른 그 창의 원문 위에, 지금 읽는 줄을 반투명 노란색으로 칠합니다.
  화면 밖으로 넘어가면 보이게 스크롤합니다. 다른 창으로 전환하면 칠이 잠시 숨습니다.
- **리더 창**: 원문 위에 칠할 수 없는 프로그램일 때만, 원문을 따로 보여 주고 읽는 줄을 칠하는 창을 띄웁니다
  (트레이 **리더 창 사용**으로 켜고 끔). 원문 위에 칠할 수 있는지 확인하는 동안에는 뜨지 않습니다.
- **브라우저에서는 쉼**: Aside·웨일·크롬은 크롬 확장(read-aloud-hrg)이 읽어 주므로, 그 브라우저 창에서는
  빨간 점이 뜨지 않고 단축키로 새로 읽지 않습니다(이 앱이 읽는 중이면 단축키로 멈출 수는 있습니다).
  트레이 **브라우저에서 비활성화**로 끄고 켭니다(기본 켬). VS Code 같은 다른 앱 안의 웹 화면은 해당하지 않습니다.
- **외국어 문장은 번역해서 읽기**: 한글이 한 글자도 없는 문장은 Gemini 로 한국어로 번역한 뒤 읽습니다.
  한국어 문장 속 영어 용어(`useState` 등)는 그대로 둡니다. 번역된 부분은 원문 자리에 짙은 회색 막으로 번역문을
  보여 줍니다(문단 일부만 보이면 노랑 형광펜). 번역이 실패하면 그 문장 차례에 읽기를 멈추고 알립니다.
- **시스템 트레이**: 트레이 아이콘으로 백그라운드에서 동작합니다 (아래 메뉴 참고).
- **설정 창**: 한국어 음성 선택(기본 `ko-KR-Chirp3-HD-Callirrhoe`)과 미리듣기, 재생 속도, 단축키, 화면 언어(한국어/English),
  번역 켜기/끄기·번역문 막 표시, API 키 설정, 콘솔 창 열기
- **중복 실행 방지**: 이미 켜져 있으면 두 번째 실행은 막힙니다.

## 요구 사항

- Windows
- Google Cloud **API 키 두 개**
  - **TTS 키**(필수): Cloud Text-to-Speech API 를 허용한 키
  - **Gemini 키**(번역용): Gemini API 를 허용한 키. 구글은 Gemini 키를 서비스 계정에 묶게 하는데, 묶인 키는
    TTS 를 부를 수 없어서 키 하나로 둘 다 쓸 수 없습니다
- 인터넷 연결
- 스피커 등 소리 출력 장치

## Google API 키 설정

1. 처음 실행할 때(또는 TTS 키가 없을 때) 키를 넣는 창이 뜹니다. 두 칸에 키를 붙여넣고 **저장**을 누릅니다.
2. 저장할 때 키마다 한 번씩 확인 요청을 보냅니다. 틀렸으면(두 칸을 바꿔 넣은 경우 포함) 이유를 보여 주고 저장하지 않습니다.
   Gemini 키 칸은 비워 둬도 저장되며, 그러면 번역할 문장이 나올 때 읽기를 멈추고 알립니다.
3. 키는 `whisperer_settings.json` 에 저장됩니다. 나중에 바꾸려면 트레이 메뉴 → **TTS 설정…** → **인증 설정** 버튼을 누릅니다.

`whisperer_settings.json` 에는 키가 그대로 들어 있으니 절대 git에 올리거나 남에게 공유하지 마세요.
(예전 방식의 `google_credentials.json` 은 더 이상 쓰지 않습니다)

## 사용 방법

1. 앱을 실행하면 트레이 아이콘이 나타납니다.
2. 아무 프로그램에서나 읽을 글을 드래그하거나 더블클릭해서 선택합니다. 선택 끝 옆에 빨간 점이 뜹니다.
3. 빨간 점을 누르거나, 단축키(기본 `Ctrl + Alt + D`)를 누릅니다.
4. 멈추려면 글을 선택하지 않은 상태에서 단축키를 다시 누르거나, 하단 재생 바의 중지 버튼을 누릅니다.

## 트레이 메뉴

트레이 아이콘을 우클릭하면 다음 항목이 있습니다.

- **TTS 설정…**: 설정 창을 엽니다
  - 음성 모델(미리듣기 포함), 재생 속도, 단축키
  - 일반: 언어(한국어/English — **저장**을 누르면 바뀌고 트레이 메뉴도 그 언어로 바뀜),
    **주 언어가 아닌 문장은 번역해서 읽기**·**번역문을 원문 위에 막으로 표시**(둘 다 기본 켬),
    **인증 설정**(API 키 두 개), **콘솔 창 열기**(실시간 로그 보기, 문제 확인용)
- **리더 창 사용** (체크): 원문 위에 칠할 수 없을 때 리더 창을 띄울지
- **브라우저에서 비활성화** (체크): Aside·웨일·크롬에서 빨간 점·단축키 쉬기 (기본 켬)
- **텍스트 선택 시 읽기 버튼** (체크): 빨간 점 켜기/끄기
- **종료**

읽기를 멈출 때는 하단 재생 바의 중지 버튼이나, 글을 선택하지 않고 단축키를 누릅니다.

## 소스에서 실행

```bash
pip install -r requirements.txt
python whisperer.py
```

메인 스크립트 이름은 아직 `whisperer.py` 그대로입니다.

## 빌드

```bash
python -m PyInstaller BluemingReadAloud.spec --noconfirm
```

- 결과물: `dist/BluemingReadAloud.exe`
- 전역 키보드 훅에 관리자 권한이 필요해서, exe를 실행하면 UAC(관리자 권한) 확인 창이 뜹니다.

## 파일

- `whisperer_settings.json`: 설정 (API 키 두 개, 언어, 단축키, 음성, 재생 속도·볼륨, 리더 창, 빨간 점 켬/끔,
  브라우저에서 비활성화, 번역·번역문 막 켬/끔, 원문 위 형광펜 켬/끔 `source_highlight_enabled` — 이 항목은 메뉴에 없고
  파일에서만 바꿀 수 있습니다)
- `logs/`: 로그 파일

모두 앱을 실행한 작업 폴더에 만들어집니다.

받아쓰기(STT) 기능은 걷어냈고, 지금은 읽어주기(TTS) 전용 앱입니다.
