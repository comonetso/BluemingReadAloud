# Yeogiaen STT Typer (여기엔 STT 타이퍼)

구글 클라우드 STT(Speech-to-Text) V2 엔진을 사용하는 한국어 최적화 음성 인식 타이핑 및 TTS 도구입니다.

## 주요 기능

1.  **고품질 음성 인식 (STT)**: Google Cloud Speech-to-Text V2를 사용하여 정확한 한국어 인식을 지원합니다.
2.  **주소 및 POI 인식 최적화**: "주소 모드"를 통해 복잡한 주소 형식을 자동으로 변환합니다. (예: "서초구 서초동 일 이 삼 다시 사" -> "서초구 서초동 123-4")
3.  **텍스트 읽어주기 (TTS)**: 선택한 텍스트를 고품질 WaveNet 음성으로 읽어줍니다. (`Ctrl + Alt + S`)
4.  **사용자 정의 단축키**: 녹음 시작/중지 및 TTS 단축키를 사용자가 직접 설정할 수 있습니다.
5.  **사후 처리 규칙**: 인식된 텍스트의 불필요한 공백이나 문장 부호를 자동으로 정리합니다.

## 사용 방법

1.  `Yeogiaen_STT_Typer.exe`를 실행합니다.
2.  트레이 아이콘에서 [Google Cloud 인증 설정]을 통해 서비스 계정 JSON 파일을 등록합니다.
3.  **STT 사용**: 설정된 단축키(기본: `Ctrl + Shift + Alt`)를 눌러 녹음을 시작하고, 다시 눌러 종료하면 텍스트가 자동으로 입력됩니다.
4.  **TTS 사용**: 텍스트를 선택(블록 지정)한 후 단축키(`Ctrl + Alt + S`)를 누르면 해당 내용을 읽어줍니다.

## 설정 변경

*   트레이 아이콘 우클릭을 통해 단축키, 인식 모델, 언어 등을 변경할 수 있습니다.
*   `whisperer_settings.json` 파일에 모든 설정이 저장됩니다.

## 요구 사항

*   Google Cloud Platform 프로젝트 및 STT/TTS API 활성화
*   서비스 계정 JSON 키 파일
