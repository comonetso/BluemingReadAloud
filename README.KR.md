# BluemingReadAloud

Google Cloud Text-to-Speech로 **선택한 글을 소리 내어 읽어 주는** 윈도우 트레이 앱입니다.
어느 프로그램에서든 글을 드래그해 선택하고 단축키를 누르면 읽어 줍니다.

## 주요 기능

- **선택한 글 읽어주기**: 글을 선택하고 단축키(기본 `Ctrl + Alt + D`)를 누르면 읽습니다.
  읽기 전에 마크다운 기호·URL·특수문자를 정리하고, 긴 글은 조각으로 나눠 끊김 없이 이어서 재생합니다.
- **단축키 하나로 세 가지 동작**
  - 글이 선택돼 있으면 → 읽기 (읽는 중이어도 새로 선택한 글로 바꿔 읽음)
  - 읽는 중인데 선택된 글이 없으면 → 중지
  - 읽고 있지 않은데 선택된 글도 없으면 → 플로팅 아이콘 보이기/숨기기
- **플로팅 아이콘**: 항상 위에 떠 있는 작은 원형 버튼입니다.
  - 클릭: 선택한 글 읽기 / 읽는 중이면 중지
  - 드래그: 위치 옮기기 (위치는 저장됨)
  - 우클릭: 숨기기
- **시스템 트레이**: 트레이 아이콘으로 백그라운드에서 동작합니다 (아래 메뉴 참고).
- **음성 설정**: 한국어 음성 선택(기본 `ko-KR-Chirp3-HD-Callirrhoe`)과 미리듣기, 재생 속도, 단축키 변경
- **한국어/영어 화면 전환**
- **중복 실행 방지**: 이미 켜져 있으면 두 번째 실행은 막힙니다.

### 개발 중

- **형광펜**: 지금 읽는 부분을 줄 단위로 칠해 보여 주기 (가능하면 원문 위에, 안 되면 별도 리더 창에)
- **하단 재생 컨트롤러**

위 두 기능은 아직 쓸 수 없습니다.

## 요구 사항

- Windows
- Cloud Text-to-Speech API가 켜진 Google Cloud 프로젝트의 **서비스 계정 JSON 키**
- 인터넷 연결
- 스피커 등 소리 출력 장치

## Google Cloud 인증

1. 처음 실행할 때(또는 쓸 수 있는 키가 없을 때) 서비스 계정 JSON 파일을 고르는 창이 뜹니다.
2. 고른 파일은 앱 폴더에 `google_credentials.json`이라는 이름으로 복사되고, 이후 이 파일로 인증합니다.
3. 나중에 바꾸려면 트레이 메뉴 → **Google Cloud 인증 설정**을 누릅니다.

`google_credentials.json`은 절대 git에 올리거나 남에게 공유하지 마세요.

## 사용 방법

1. 앱을 실행하면 트레이 아이콘과 플로팅 아이콘이 나타납니다.
2. 아무 프로그램에서나 읽을 글을 선택합니다.
3. 단축키(기본 `Ctrl + Alt + D`)를 누르거나 플로팅 아이콘을 클릭합니다.
4. 멈추려면 글을 선택하지 않은 상태에서 단축키를 다시 누르거나, 플로팅 아이콘을 클릭합니다.

## 트레이 메뉴

트레이 아이콘을 우클릭하면 다음 항목이 있습니다.

- **TTS 설정**: 음성 모델(미리듣기 포함), 재생 속도, 단축키
- **Google Cloud 인증 설정**: 서비스 계정 JSON 키 교체
- **언어 변경 (한/영)**
- **README 파일 열기**
- **콘솔 창 열기**: 실시간 로그 보기 (문제 확인용)
- **⏹ TTS 중지** (읽는 중일 때만 누를 수 있음)
- **플로팅 아이콘 숨기기 / 보이기**: 숨긴 아이콘은 여기서 언제든 다시 꺼낼 수 있습니다
- **종료**

## 소스에서 실행

```bash
pip install -r requirements.txt
python whisperer.py
```

메인 스크립트 이름은 아직 `whisperer.py` 그대로입니다.

## 빌드

```bash
python -m PyInstaller BluemingReadAloud.spec --noconfirm
```

- 결과물: `dist/BluemingReadAloud.exe`
- 전역 키보드 훅에 관리자 권한이 필요해서, exe를 실행하면 UAC(관리자 권한) 확인 창이 뜹니다.

## 파일

- `whisperer_settings.json`: 설정 (언어, 단축키, 음성, 재생 속도, 플로팅 아이콘 위치·숨김 여부)
- `google_credentials.json`: Google Cloud 서비스 계정 키
- `logs/`: 로그 파일

모두 앱을 실행한 작업 폴더에 만들어집니다.

## 내력

2025년 LMTY Yeogiaen Service Co., Ltd.에서 "여기엔 STT 타이퍼(Yeogiaen STT Typer)"(음성 받아쓰기 + 읽어주기)로 처음 만들었습니다.
받아쓰기(STT) 기능은 걷어냈고, 지금은 읽어주기(TTS) 전용 앱입니다.
