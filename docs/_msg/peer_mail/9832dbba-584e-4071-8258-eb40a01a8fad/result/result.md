바꾼 것
1. 읽는 글: spokenText.ts 를 spoken_text.py 로 줄마다 옮김. 그쪽 시험 기대값(test_spoken_symbols 86건 · spoken_version 10건)을 고치지 않고 옮겨 모두 같은 결과. 파이썬 re 에 \p{...} 가 없어 node(Unicode 16.0)로 뽑은 구간표(spoken_unicode.py)를 씀
2. 문단 단위: 빈 줄 문단(splitParagraphs 규칙)으로 읽고, 형광펜·이전/다음도 문단 단위. 한 요청 2000바이트 이하 문장 경계(splitInput 이식)
3. 음성: 기본 목소리 Zephyr(전엔 Callirrhoe), markup 은 400 일 때만 평문으로 한 번 다시(인증·한도·시간 초과는 바로 실패), 합성은 1.0 + 재생에서 빠르기
4. 키(Windows 전역): Ctrl+Space 멈춤·다시 · Ctrl+← 이전 문단 · Ctrl+→ 다음 문단 · Ctrl+↓ 느리게 · Ctrl+↑ 빠르게. 읽기 있을 때만 가로채고 멈춘 동안은 Ctrl+Space 만, 읽기 없으면 다 넘김(listenTtsSpeedKeys 와 같은 규칙). 이전 = 지금 문단 3초 넘게 읽었으면 그 문단 처음
5. 빠르기: 0.1 → 0.5~2배, 0.25 → 0.5~5배. normalizeRate · rateOptions(목록은 1배 이상 + 지금 값이 1배 아래면 그 하나) · speedLabel("1.0x"·"2x") 그대로
