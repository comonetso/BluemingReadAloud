■ 바꾼 곳
1. 옵션 화면 단축키 칸 — 맨 아래 버튼 줄(음성 시험·초기화 옆)에 "단축키 바꾸기" 버튼을 넣었습니다. 누르면 그 아래 다섯 칸이 펼쳐지고, 다시 누르면 접힙니다(options.html·css/options.css). 칸을 누르고 키를 누르면 저장, Esc 는 취소, 다른 동작과 같은 키면 저장하지 않고 "이미 ○○에 쓰는 키" 안내(js/options.js — defaults.js comboOfKey·readingKeyConflict). 읽는 중이면 바뀐 키가 바로 들어갑니다. 문구 9개 en/ko(options_reading_key*)
