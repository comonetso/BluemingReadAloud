## 할 일 (read-aloud-hrg)
1. 설정 페이지(options.html)
   - 속도 막대(#rate)·직접 입력 칸(#rate-input)·편집 버튼(#rate-edit-button)을 없애고
     "속도 간격" 선택 칸 하나만 둔다: 0.1 / 0.25, 처음(기본)은 0.1. 간격 값은 설정으로 저장한다.
2. 웹페이지 아래 재생 바(페이지 UI)
   - 닫기 버튼 바로 옆에 "속도" 선택 상자를 둔다. 지금 속도(예: "1.3x")가 보이고, 누르면 목록이 펼쳐진다.
     - 간격 0.1  → 0.7, 0.8, 0.9 … 2.0배 (14개)
     - 간격 0.25 → 0.5, 0.75, 1.0 … 3.0배 (11개)
   - 고르면 읽는 중인 소리에 바로 반영하고 설정으로 저장한다.
   - 음성 설정 패널(톱니)의 속도 막대는 뺀다. 볼륨 막대는 이번 요청 범위가 아니다(그대로 둔다).
3. 맞춤 규칙
   - 저장된 속도가 목록에 없으면(예: 0.33배, 1.37배) 가장 가까운 목록 값으로 맞춘다. 정확히 가운데면 빠른 쪽.
     (예: 간격 0.25 의 1.25배 → 간격 0.1 로 바꾸면 1.3배)
   - 설정 페이지에서 간격을 바꾸면 지금 속도도 같은 규칙으로 새 목록 값에 맞춘다.
