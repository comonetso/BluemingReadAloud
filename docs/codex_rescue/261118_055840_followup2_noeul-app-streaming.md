# 되묻기 2턴 — 쓰기 거부가 풀렸다. 1턴 요청서의 작업을 이번에 실제로 구현해라

## 이 턴의 성격
네 1턴 분석을 내가 검토했다(응답 문서 `## Claude 검토`). 1턴은 저장소 쓰기가 막혀 코드 0줄로 끝났다.
이번 턴은 **1턴 요청서(`docs/codex_rescue/261118_055840_request_noeul-app-streaming.md`)의 "작업 — 직접 수정할 것" 1~6을 실제로 구현하는 턴**이다.
리규형님이 이번 턴의 코드 수정을 승인했다(gpt-6.1-sol · xhigh · 깊게).
아래는 내가 네 분석을 어떻게 읽었는지다. **내가 좁게 읽었을 수 있다.** 틀린 곳이 있으면 그것부터 바로잡고 구현해라.
요청서의 "리규형님 결정(바꾸지 마라)"·"Paseo 실측·규칙"·"작업 규칙"은 이 턴에도 그대로다 — 요청서를 다시 열어 읽고 시작해라.

## 내가 네 분석을 이렇게 읽었다
- 너는 쓰기 실패를 Windows 샌드박스의 Access denied 로 보고했고, 나는 원인을 **저장소 폴더 소유자가 `BUILTIN\Administrators`** 였던 것으로 이해했다. 소유자를 되찾아 풀었다(아래 새 정보).
- 너는 "목록만 더하면 안 되고, 초기화 검사·합성기·미리 듣기·재생기·노을 전달·취소·문단 경계·계획 속도·사용량"의 9곳을 함께 바꿔야 한다고 했다. 나는 그것을 **이번 구현의 체크리스트**로 받았다.
- 너는 재생기가 빈 블록을 조각 끝으로 처리한다(`tts_engine.py:1203`)는 것을 가장 위험한 곳으로 짚었다. 나는 "받는 대로 틀기에서 '아직 안 옴'과 '다 됨'을 가르지 않으면 받는 중인 문단을 건너뛴다"로 읽었다.
- ⚠️ 내가 자신 없는 해석: 받는 대로 틀기를 엔진의 **어느 층**에 둘지. 요청서의 내 가설(문단마다 자라는 소리 객체를 `_ready` 에 넣고 재생 스레드가 기다림)과 너의 표(수신 중 PCM 보관·기다리는 경로 + 끝나지 않은 입력을 이어 받는 WSOLA)가 같은 설계를 뜻하는지 나는 확인하지 못했다. 원본이 더 나은 자리를 가리키면 그쪽으로 가라. 단 Google 읽기 경로는 바뀌면 안 된다.

## 이번 턴에 묻는 것
1. **요청서 "작업 — 직접 수정할 것" 1~6을 구현해라.** 위 표의 연결 지점을 모두 반영해라.
   - 고쳐도 되는 파일: `tts_engine.py` · `noeul_live.py` · `whisperer.py` · `tts_usage.py` · `readaloud_text.py` · `translation.py` · `tests/` 안(새 시험 파일 포함). 그 밖의 운영 파일은 건드리지 마라.
   - 기대 동작:
     - 설정 창 목소리 목록 맨 끝에 노을이 보이고, 저장·불러오기·미리 듣기가 노을로 된다.
     - 노을로 읽으면 문단마다 Paseo `streamPiecesGrowing` 대로 조각을 계획하고, 조각마다 노을 연결 하나를 연다(문단 안 최대 8, 전체 상한 `noeul_live.LIVE_SESSIONS_MAX`).
     - 받은 소리는 오는 대로 재생 쪽에 넘기고, 시작 전 모음만큼 모이면 틀기 시작한다. 모자라면 기다린다 — 문단을 건너뛰지 않는다.
     - 번역·원문 위 형광펜·Ctrl+←/→ 문단 이동·Ctrl+↑/↓ 빠르기(재생 때 WSOLA)·Ctrl+Space 멈춤/재개·끝내기가 Google 때와 같이 문단 단위로 돈다.
     - 노을 실패(no_key·IP 불허·키 거절·다시 시도 소진)는 그 문단 차례에 멈추고 `tts_engine.SegmentFailed` 경로로 경고 창을 띄운다(문장 = `noeul_live.MESSAGES`).
     - 이동·끝내기 때 미리 연 노을 연결을 닫는다. 멈춤 때는 닫지 않는다.
     - 사용량은 성공한 조각마다 `UsageCounter.count("openai", 조각 글, key=OpenAI key_mark)` — `months` 와 `keys` 두 곳. 다시 시도로 버린 연결·실패한 연결·확장 창구(`/v1/tts/noeul`) 몫은 세지 않는다.
     - Google 읽기 동작은 그대로다.
2. 시험(요청서 작업 6)을 더하고, 끝에 `PYTHONUTF8=1 python -m unittest discover -s tests` 전체를 돌려 결과를 적어라.
3. 🔴 실제 OpenAI 를 부르지 마라. 앱 실행·빌드·git 상태 변경·패키지 설치도 하지 마라(요청서 작업 규칙).
