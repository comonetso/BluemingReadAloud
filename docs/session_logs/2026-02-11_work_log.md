# 2026-02-11 작업 로그

## 작업 요약
- 플로팅 미니 STT 녹음 컨트롤러 구현 (신규 기능)

## 완료된 작업
- 28px 원형 플로팅 컨트롤러 구현 (항상 최상위 표시)
- 클릭으로 녹음 시작/중지 토글
- 드래그로 위치 이동 (5px 임계값으로 클릭/드래그 판정)
- 위치를 `whisperer_settings.json`에 자동 저장/복원
- Win32 API로 안정성 확보:
  - 소유자 창 분리 (`SetWindowLongPtrW`) → root.withdraw()와 독립
  - 포커스 탈취 방지 (`WS_EX_NOACTIVATE`) → 커서 위치 유지
  - TOPMOST 확정 (`SetWindowPos`) → 항상 위 보장
  - 원형 클리핑 (`CreateEllipticRgn`) → 둥근 외형
- 상태별 색상: 초록(대기, 흰 원) ↔ 빨간 깜빡임(녹음 중, 흰 사각형)
- 3초 주기 topmost 재적용으로 사라짐 방지
- PyInstaller 빌드 완료 (`dist/Yeogiaen_STT_Typer.exe`)

## 변경된 파일
- `whisperer.py` — 전역변수 3개, save/load_settings 수정, `setup_floating_controller()` 함수 신규
- `messages.py` — `controller_created`, `controller_position_saved` 메시지 ko/en 추가

## 주의사항
- `-transparentcolor` 속성은 Windows에서 불안정 → 사용 금지 (배경=버튼색으로 대체)
- `WS_EX_NOACTIVATE` 설정 시 tkinter 이벤트는 정상 수신됨 (테스트 확인)
- 컨트롤러 위치가 다중모니터 좌표(음수 x)로 저장될 수 있음 → 정상 동작
