3. **on_press/on_release 경량화** — 모든 logging.debug 호출 제거 (Windows 훅 타임아웃 방지)
4. **키보드 리스너 watchdog 추가** — 리스너 스레드 사망 시 30초마다 자동 재시작
5. **다중 실행 방지 강화** — Windows Mutex + 소켓 포트(51888) 이중 방어
6. **spec hiddenimports 보강** — pynput._win32 하위 모듈 명시적 포함
