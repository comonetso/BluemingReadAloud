## 완료된 작업
- **[기능] 텍스트 필터링 강화:** 괄호 내용 제거 및 언더스코어(`_`), 하이픈(`-`)을 공백으로 치환하여 "밑줄" 발음 버그 해결
- **[기능] SSML 휴식 태그 적용:** 콜론(`:`)은 0.5초, 콤마(`,`)는 0.3초 쉬어 읽도록 튜닝하여 가독성 증대
- **[기능] 한/영 하이브리드 발음 구현:** 텍스트를 언어별로 분절하여 한국어는 `ko-KR`, 영어는 `en-US` 원어민 모델로 각각 합성 후 병합 재생
- **[빌드] 최신 버전 실행 파일 생성:** 고도화 로직이 모두 포함된 `dist/Yeogiaen_STT_Typer.exe` 빌드 완료
