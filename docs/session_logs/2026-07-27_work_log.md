## 1. 작업 흐름 (커밋으로 복원 불가한 맥락만)

### 1-1. 최초 요구 — 플로팅 아이콘이 항상 떠 있어 불편
**배경**: 사용자가 STT를 거의 쓰지 않는 상태(`stt_enabled: false` → `controller_mode = 'tts'`). 플로팅 아이콘이 TTS 버튼으로만 동작하는데 상시 표시라 거슬림.
**초기 요구**: 플로팅 우클릭 → 숨기기 / 복원은 "트레이 컨텍스트 메뉴의 안 쓰는 항목(사용자 표현 'STT재생')으로 대체".
**확정**: 조사 결과 사용자가 지목한 항목은 트레이의 `▶ TTS 재생`으로 추정됨. 질문 결과 **대체가 아니라 신규 추가**로 결정(기존 기능 손실 회피).

### 1-2. 중간 발의 — 사용자가 스스로 설계 충돌을 감지
사용자가 "TTS 단축키로 플로팅 보이기" 아이디어를 냈다가 **스스로 철회**: "숨김 상태에서 TTS를 해야 하는데 단순히 '보이기'로 하면 기능 충돌이 있겠다".
→ 조사 결과 **전제 2건이 틀렸음을 확인하고 정정**(§3-2). 그 과정에서 진짜 갭(중지 수단)과 기존 결함(클립보드 오독)이 함께 드러남.

### 1-3. 최종 확장 — 단축키 완전 토글
사용자 발의로 "선택 없을 때 숨기기도 단축키로" 추가. 동시에 "메뉴에서 빼도 될 것 같다"는 제안이 나왔으나 **트레이 메뉴는 비상 복구용으로 유지 강력 권고 → 사용자 수용**(§2 표 참조).

## 3. 시행착오

### 3-1. 트레이 라벨이 안 뒤집히는 버그 (사용자 발견)
- **잘못된 가정**: 상태 전역(`controller_hidden`)만 바꾸면 트레이 메뉴가 알아서 따라올 것
- **발견 경위**: 사용자 실사용 — "플로팅에서 숨기기하면 트레이에 계속 숨기기가 나온다"
- **원인**: pystray 메뉴 라벨은 `update_tray_menu()` 재호출 시에만 재평가됨. 트레이 경로(`check_gui_queue`)만 이를 호출했고 플로팅 우클릭 경로는 호출하지 않음
- **복구**: `update_tray_menu`가 `setup_tray_icon` 내부 중첩 함수라 외부 접근 불가 → 전역 `tray_menu_updater`로 참조 노출([whisperer.py:1600](../../whisperer.py#L1600)) → `set_controller_visible()` 안에서 항상 호출
- **교훈**: 상태 변경 함수가 **갱신 책임까지 함께 진다**. 진입점이 3개(단축키·우클릭·트레이)로 늘어도 버그가 재발하지 않는 구조.

### 3-2. 사용자 전제 2건 정정 — "숨기면 TTS를 못 쓴다"는 성립하지 않음
- **정정 1**: TTS 단축키는 pynput 전역 리스너([whisperer.py:909](../../whisperer.py#L909))가 처리하며 **플로팅 창과 코드 경로가 완전히 분리**됨. 숨겨도 읽기는 100% 작동. 플로팅 클릭은 또 하나의 진입점일 뿐.
- **정정 2**: 진짜 갭은 시작이 아니라 **중지**. 중지 수단이 플로팅 클릭 / 트레이 메뉴 둘뿐이라 숨기면 트레이만 남음.
- **교훈**: 사용자가 감지한 "충돌"이 실재해도 **원인 지목은 틀릴 수 있다**. 코드로 확인 후 방향을 재설정해야 정확한 해법이 나온다.

### 3-3. `pyinstaller` 명령 부재 (빌드 1차 실패)
- **증상**: `pyinstaller Yeogiaen_WhisperTyper.spec` → `command not found`. 그런데 `echo`가 뒤따라 **exit code 0으로 오인 보고될 뻔함**
- **원인**: PATH에 스크립트 없음. 모듈로는 정상(`python -m PyInstaller --version` → 6.15.0)
- **복구**: `python -m PyInstaller Yeogiaen_WhisperTyper.spec --noconfirm`, 종료 코드는 `RC=$?`로 별도 캡처
- **교훈**: `cmd > log 2>&1; echo ...` 형태는 마지막 `echo`의 성공 코드를 반환한다. 빌드 성공 판정은 **산출물 타임스탬프**로 교차 확인할 것.

## 4. 발견한 코드베이스 함정 ★

1. **`read_selected_text`의 "선택 없음" 판별 결함 (수정 완료)** — Ctrl+C를 눌러도 선택이 없으면 클립보드가 **변하지 않는다**. 기존 코드는 `if new_text and len(new_text.strip()) > 0`으로 통과시켜 **직전 클립보드를 읽어버렸다**. `"읽을 텍스트가 선택되지 않았습니다"` 분기는 **도달 불가능한 죽은 코드**였음. → Ctrl+C 직전 `pyperclip.copy("")`로 비워야 확실히 판별된다.

2. **`is_speaking`은 죽은 변수** — [whisperer.py:884](../../whisperer.py#L884)의 TTS 단축키 가드 `not is_speaking`은 사실상 항상 True. `is_speaking`은 미사용 함수(`toggle_tts_playback`, `replay_last_tts`)에서만 갱신되고, 실제 재생 경로는 `tts_playing`을 쓴다. **TTS 재생 중 상태를 판단할 땐 `tts_playing`을 봐야 한다.**

3. **`update_state()` 루프가 숨긴 창을 되살릴 수 있다** — 500ms 루프가 3초마다 `attributes('-topmost', True)` + `lift()`를 호출한다. `winfo_exists()`는 `withdraw()` 후에도 True라 루프가 계속 돈다. **숨김 가드 없이 withdraw만 하면 안 된다.**

4. **플로팅 창은 `WS_EX_NOACTIVATE`라 포커스를 못 받는다** — tkinter 팝업 메뉴를 이 창의 자식으로 만들면 바깥 클릭 시 닫히지 않을 수 있다. **반드시 `root`의 자식으로 생성**할 것. 또한 이 창은 `HWND_TOPMOST`라 메뉴가 떠 있을 때 `lift()`가 돌면 아이콘이 메뉴를 가린다 → `menu_open` 플래그로 차단.

5. **tkinter는 스레드 안전하지 않다** — pystray 트레이는 별도 스레드([whisperer.py:1633](../../whisperer.py#L1633)). 트레이 콜백에서 `withdraw`/`deiconify`를 직접 부르면 안 되고 `gui_queue` → `check_gui_queue` 경유가 필수.

6. **빌드 명령은 `python -m PyInstaller`** — CLAUDE.md에 적힌 `pyinstaller ...`는 이 환경에서 동작하지 않는다(§3-3).
