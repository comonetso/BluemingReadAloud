## 3. 시행착오
- **UIA 전체 탐색으로 VS Code 얼림** — .NET UIA 로 VS Code 창의 TextPattern 요소 1,600개를 차례로 조회 → 3분 넘게 멈춤, 사용자 재시작. 교훈: 한 자리만, 시간 제한, 사전 허락.
- **첫 UIA 실측 "TextPattern 없음"** — `GetCurrentPatternAs` 방식이 실패했을 뿐, 조상 Document 에서 `GetCurrentPattern + QueryInterface` 로는 성공.
- **"이름표(Mutex) 판정 오류"로 잘못 진단** — 깨진 로그의 4바이트가 "소켓"(한글 2자)이었다. 실제 원인은 TeamViewer 포트 점유.
- **`end` 호출이 없다고 오진** — `_safe_ui("…", hl.end)` 모양이라 grep 패턴에 안 걸렸을 뿐.
- **"VS Code 리더 창 끄기 힘들다" 오해** — 사용자는 VS Code 에서 리더 창이 아예 뜨지 않길 원했다(원문 위 형광펜).
- **빨간 점 바탕화면 필터가 동작 안 함** — `_no_dot_window_at` 가 떼어 실행한 실측에서 작업 표시줄조차 False. 원인 미규명, "선택 확인" 방식으로 대체.
- **속도 WSOLA 도입 후 테스트 26개 실패** — 가짜 소리 샘플 값에 조각 번호를 새겨 판별하던 테스트가 WSOLA 로 값이 바뀌어 깨짐 → 속도 1.0 이면 원본 그대로 내보내기로 7개로 줄이고, 나머지 7개는 새 동작 기준으로 교체.
- **절전 문제로 워크플로우를 멈췄는데 사용자는 "바로 자겠다는 게 아니다, 끝내야지"** — 의도를 확인하지 않고 멈췄다.

## 4. 발견한 코드베이스 함정

1. **VS Code(Electron) 채팅·미리보기의 UIA 구조** — 포커스 요소(채팅 컨테이너)·메시지·문단 요소에는 TextPattern 이 없고, 위로 약 4단계의 **Document(ControlType 50030)** 에만 `IsTextPatternAvailable=true`. `doc.GetCurrentPattern(UIA_TextPatternId).QueryInterface(IUIAutomationTextPattern)` 은 되고 `GetCurrentPatternAs` 는 실패. `RangeFromPoint→ExpandToEnclosingUnit(Line)→GetBoundingRectangles` 1~2ms. **금지**: GetVisibleRanges·DocumentRange 전체·FindAll(Descendants) — VS Code 얼림. (`source_highlight.py`)
2. **단축키 글자가 다른 앱에 입력됨** — pynput Listener 는 키를 알아보기만 하고 흘려보낸다. 메모장·워드에서 Shift+X 가 "X" 로 선택 글을 덮어썼다. → `win32_event_filter` 에서 단축키 글자 키의 누름·뗌(자동 반복 포함)만 `suppress_event()`. suppress_event 는 예외로 알리므로 try 밖에서 호출. 앱이 흉내 낸 입력(LLKHF_INJECTED)은 건드리지 않는다. (`whisperer.py setup_keyboard_listener win32_filter`)
3. **안 눌린 Alt 의 "뗌" 주입 → 새 메모장 메뉴 모드** — read_selected_text 가 Ctrl·Alt·Shift 뗌을 무조건 보내서 Windows 11 메모장이 메뉴 키 팁(F·E·V…)을 띄우고 Ctrl+C 가 메뉴로 갔다(= 메모장에서 빨간 점·단축키가 "선택 없음"). → GetAsyncKeyState 로 실제 눌린 수정자만 떼고, Alt 가 눌려 있으면 떼기 전에 Ctrl 을 한 번 눌렀다 뗀다(Alt 단독 탭 방지).
4. **단일 실행 소켓 백업(UDP 51888)을 TeamViewer_Service 가 점유** — Mutex 가 성공해도 소켓 검사를 늘 해서 "이미 실행 중"으로 꺼졌다. → Mutex 성공 시 소켓 생략(docstring 원래 의도).
5. **Inno Setup** — `CloseApplications=yes` 면 트레이 앱(보이는 창 없음)이 Restart Manager 요청에 응답 못 해 "응용 프로그램을 닫는 중"에서 멈춤 → `force`. `[Run] postinstall` 은 기본으로 원래 사용자 권한 보조 프로세스(spawn server)로 띄우는데 exe 가 requireAdministrator 라 "CallSpawnServer: Unexpected response: $0" → `runascurrentuser`.
6. **audiotsm WSOLA 끝 약 80ms 손실** — 3초 72000 → 70144 샘플. 끝 음절 잘림 방지로 원본 끝에 무음 2048 샘플(`_Stretcher.TAIL_PAD`). 속도 1.0 이면 WSOLA 를 거치지 않고 원본 그대로(음질·기존 테스트 보존).
7. **빨간 점 드래그 추정의 한계** — `SM_CXDRAG=4` 는 배율 140% 화면에서 클릭 떨림으로도 넘는다 → 클릭만으로 점. 창 제목 끌기·스크롤바·바탕화면 아이콘 선택도 드래그. → UIA 로 선택 끝 한 자리 조회 후 선택이 있을 때만(`_handle_selection_button_msg` "show").
8. **`dist\` = 사용자 데이터 폴더** — 옛 exe 를 dist 에서 실행해 와서 인증·설정·recordings·logs 가 있다. 클린 빌드 때 통째로 지우면 안 된다.
9. **comtypes.gen 은 실행 중 생성되는 모듈** — PyInstaller 가 모르므로 `hiddenimports` 에 `comtypes.gen.UIAutomationClient`·`_944DE083_…` 등을 명시해야 exe 에서 원문 형광펜이 된다. audiotsm 도 함수 안 import 라 명시.
10. **트레이 메뉴는 윈도우가 그리는 Win32 메뉴** — ttkbootstrap 테마가 닿지 않는다 → uxtheme 서수 135 SetPreferredAppMode(2=ForceDark) + 136 FlushMenuThemes(비공개 함수, 실패 시 조용히 넘어감).
11. **pystray 윈도우판은 `enabled`/`checked` 를 메뉴를 만들 때 한 번만 읽는다** — 상태가 바뀌면 `update_tray_menu()` 로 다시 만들어야 한다(3차 검증).
12. **Tk Text 는 이모지를 "줄.칸" 인덱스에서 2칸으로 센다**(Tk 8.6.15) — `reader_window.TkTextOffsets` 가 보정.
13. **확장 저장소는 다른 세션이 동시에 고치는 중일 수 있다** — 확장 코드는 `git show HEAD:<경로>` 로만 읽는다. 이 세션 중에도 HEAD 가 두 번 움직였다.
