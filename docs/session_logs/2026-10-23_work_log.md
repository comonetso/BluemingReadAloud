## 4. 발견한 코드베이스 함정

- **크로미움 문서 요소의 값 = 페이지 주소**: 포커스에서 위로 처음 만나는 Document(ControlType 50030)의 `UIA_ValueValuePropertyId`(LegacyIAccessible Value 도 같음)가 `https://…`. Aside 일반 페이지에선 포커스가 곧 문서. **링크·썸네일(Hyperlink 50005)에 포커스가 있으면 그 요소의 값도 주소지만 링크 대상**이다 → 문서 요소의 값만 써야 한다(`_page_scheme`). iframe 안 포커스면 iframe 문서 주소를 본다(더 위로 걷지 않음 — 한계).
- **Aside 새 탭 = `chrome-extension://…`**(문서 이름 "New Tab", 7자). 크롬 확장은 이 페이지에 못 들어간다.
- **브라우저 테두리(탭 줄·주소창) 포커스**: `Chrome_WidgetWin_1` → `MultiContentsView` → `BrowserView` → `BrowserFrameViewWin` → `NonClientView` → `BrowserRootView` … 전부 Pane(50033), 문서가 없다 → 주소 모름.
- **Aside 가 UIA 한 호출에 가끔 2.4초**(측정 17:27:17). 설치본 로그에도 `GetFocusedElement: 2.02s`(10-23 12:21, 앱 미상). 1초 제한으로 "모름"이 된다.
- **텔레그램 메시지 항목(ListItem 50007)은 SelectionItem 패턴을 지원**: 우클릭 "선택" → `IsSelected=True`, LegacyIAccessible 상태 비트 0x2. 선택 아닐 때 상태 0x1300000, 선택+포커스 0x1300006.
- **텔레그램 왼쪽 대화 목록(`Dialogs::InnerWidget` 아래 ListItem)도 열린 대화가 `IsSelected=True`** → 메시지 목록(`HistoryInner`) 부모인 항목만 봐야 한다.
- **Qt ClassName 은 `class HistoryInner` 처럼 "class " 가 붙어 온다** → 포함 비교.
- **텔레그램 우클릭 메뉴가 떠 있는 동안**: 포커스 `Ui::PopupMenu`(Menu 50009), 마우스 아래 `Ui::Menu::Action`(MenuItem 50011). "선택"을 뗀 순간에도 아직 이 상태일 수 있다.
- **텔레그램 선택 상태에서 Ctrl+C = 선택 메시지 글 복사**(한 개 선택 기준 머리말 없음 — 설치본 로그 17:28:57). 두 개 이상 선택했을 때의 복사 형식은 확인 안 함.
- **`ElementFromPoint` 는 관리자 창·작업 표시줄 위에서 "액세스 거부"(-2147024891)**, 메뉴가 사라지는 순간엔 "이벤트에서 가입자를 불러낼 수 없습니다"(-2147220991) → 그 요소만 건너뛴다.
- **comtypes 는 import 순간 COM 을 초기화**(기본 단일 스레드 방식). 다중 스레드 방식이 필요하면 import 전에 `sys.coinit_flags = 0`.
- **`source_highlight` 의 `root.after(0, on_done, None)` 은 테스트의 가짜 Tk(`FakeRoot.after(ms, fn)`)와 안 맞는다** — 그 경로를 테스트한 적이 없어 숨어 있었다. `lambda: on_done(None)` 으로 바꿈(`_one_shot_query`).
- **단일 실행 포트 51888 은 UDP** — `netstat -ano -p UDP | grep :51888` 로 비었는지 본다.
