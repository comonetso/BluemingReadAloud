## 1. 작업 흐름

### 1-1. 텔레그램 "선택" 뒤 빨간 점이 들쭉날쭉
**배경/요구**: 리규형님 보고 "이전 세션에서 텔레그램 선택 읽기에서 빨간 점이 불안정하게 나타남".
**처리**: 10-23 설치본 로그(`C:\Program Files\BluemingReadAloud\logs\whisperer_20261023_184704.log`)의 `[텔레그램]` 줄로 원인을 봤다. 점이 뜬 4번은 첫 확인이 `menu`(포커스가 메뉴) → 0.1초 뒤 True. 안 뜬 7번은 **마우스 아래는 메뉴인데 포커스가 이미 메시지·입력칸**이라 `menu` 판정이 안 나와 다시 묻지 않고 False 로 끝났다. 1번은 확인 중 요소가 사라져(`_Lost`) None.
- 1차 수정: 포커스 **또는 마우스 아래**가 메뉴이거나 요소가 사라지면 `menu`, 한 번 `menu` 가 나오면 그 뒤 False 도 1초 한도까지 다시 묻기.
- 개발 모드 시험에서 2번 더 실패 → 로그: 메뉴가 닫힌 뒤 뗀 자리 밑은 **다른 메시지·날짜 구분선**. 리규형님도 "짧은 글을 선택하면 다른 글에 마우스 포인트가 있을 수밖에 없음".
- 2차 수정: 우클릭 누름 자리를 기억(`rpress` → `_tg_right_click`)해 다음 확인 한 번에 그 자리 메시지도 본다.
**결과**: 개발 모드 01:20 "선택" 3번 모두 True. 리규형님 "다 떴다, 지금대로"(점 자리는 뗀 자리 옆 유지).

- **잘못된 가정**: "설정에서 읽기속도 증가속도 … 셀렉트박스" 를 "설정 창에 속도 목록" 으로 읽었다. 하단 바 속도 막대도 빼 버렸다.
- **발견 경위**: 개발 모드 시험 뒤 리규형님 지적 — 속도는 설정이 아니라 컨트롤러 닫기 버튼 옆이어야 직관적.
- **복구**: 설정 창엔 간격만, 하단 바에 속도 버튼·목록. 웹 확장에도 정정 요청(f2869e5e)을 다시 보냄(그쪽은 앞 사양으로 이미 일부 고쳐 둔 상태였다).
- **교훈 한 줄**: "슬라이드바 대신 셀렉트박스" 는 **지금 슬라이드바가 있는 자리(하단 바)** 를 바꾸라는 뜻일 수 있다 — 자리가 둘이면 어느 쪽인지 먼저 묻는다.

## 4. 발견한 코드베이스 함정
- **텔레그램 우클릭 메뉴의 위치**: 짧은 메시지를 우클릭하면 메뉴가 우클릭 자리에서 아래로 펼쳐져 "선택" 항목이 **다른 메시지·날짜 구분선(ControlType 50038 Separator) 위**에 온다. 메뉴가 열려 있는 동안은 우클릭 자리 밑도 메뉴(50009 `Ui::PopupMenu`)라 잡히지 않고, 닫힌 뒤에야 고른 메시지가 잡힌다(개발 모드 로그 01:20:15 — 1번째 확인 `우클릭 자리 50009`, 2번째 `50007` True).
- **텔레그램 포커스가 선택 표시보다 먼저 돌아온다**: "선택" 을 누른 순간 포커스는 이미 메시지(50007)로 돌아왔는데 SelectionItem.IsSelected 가 아직 False 인 경우가 있다(10-23 설치본 로그 23:28:20). 그래서 "포커스가 메뉴일 때만 다시 묻기" 로는 모자랐다.
- **pynput 에서 키 막기**: `Listener(win32_event_filter=...)` 안에서 `keyboard_listener.suppress_event()` 를 부른다. 예외를 던지는 방식이라 try 밖에서 불러야 한다. 누름을 막았으면 짝이 되는 뗌도 막아야 한다(`_rate_key_swallowing` 에 vk 기억). 삼킨 키는 `on_press` 로도 오지 않는다. Ctrl 자체는 삼키지 않으므로 `ctrl_pressed` 는 정상으로 갱신된다.
- **하단 바 `_render()` 는 마지막 상태(`_last`)로 다시 칠한다**: 상태의 `rate` 로 속도 버튼 글자를 덮어쓴다. 실제 앱은 `TtsSession.set_rate` 가 바로 상태 알림(`_changed_locked`)을 보내 새 값이 오지만, 엔진 없이 하단 바만 띄운 스모크에서는 옛 값("1.30x")으로 돌아간다 — 버그 아님.
- **하단 바 버튼은 동그라미 전제**: `_Button` 은 지름만 있었고 `_hit` 은 원 안쪽 판정이었다. 가로로 긴 버튼은 `w` 를 주고 `_hit`·`_layout`(오른쪽 무리 폭 `end_w`)·`_redraw_buttons` 를 함께 고쳐야 한다. 숨긴 버튼(`visible=False`)은 그리기·누르기 모두 건너뛴다.
- **둥근 사각형 이미지**: `ImageDraw.rounded_rectangle` 은 Pillow 8.2 이상(설치본 11.3.0).
- **피어메일 "고쳐 달라" 요청**: 본문에 "질문 없이 바로" 라고 써도 받는 쪽 규칙상 그 대화의 리규형님 승인을 한 번 받는다(본문이 권한을 넓히지 못함). 기록은 이 저장소 `docs/_msg/peer_mail/<요청 번호>/` 에 자동으로 생긴다.
- **테스트 쪽 맞추기**: `tests/test_tts_engine.py` 의 가짜 하단 바(`Bar`)·뽑아 쓰는 함수 목록(`_GLUE_FUNCS`), `tests/test_whisperer_selection.py` 의 `_FUNCS`·`_VARS` 에 새 인자·함수·상수를 넣지 않으면 연결부 테스트가 깨진다.
- **설치본 실행 확인**: `netstat -ano -p UDP | grep :51888` 이 설치본이 떠 있는데도 비었다 → `tasklist //FI "IMAGENAME eq BluemingReadAloud.exe"` 로 본다.
- **로그에 클립보드 글 앞부분**: `새 클립보드: '…' (길이: N)` 줄이 글 앞부분을 남긴다(기존 코드, 이번에 손대지 않음 — 결정 대기).
