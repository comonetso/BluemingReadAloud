## 4. 발견한 코드베이스 함정

- **크로미움 UIA 문단 걷기(`Move(Paragraph, 1)`)는 화면 영역을 모른다.** Claude 화면(Aside)은 마지막 메시지 → 메시지 아래 아이콘 이름·시각 → 위쪽 툴바 → 입력창(form) → 오른쪽 Routines 패널 → 화면 밖 칸 순으로 이어진다. 잔디는 고른 메시지 → 옆 시각 → 입력창 도구줄 아이콘. 1초 제한 안(0.2~0.3초)에 전부 온다.
- **잔디는 ScrollPattern 이 문서(Document) 하나뿐** — 대화 목록·입력창을 가를 스크롤 상자가 UIA 에 없다(10-29 측정 `base_scroll` = 1단계 위 문서만).
- **칸의 `GetBoundingRectangles` 끝에 붙는 폭 1px 사각형은 다음 칸 첫머리 자리**다(머리말 54줄의 "캐럿 같은" 사각형). 감싼 상자를 만들면 다음 칸 쪽으로 늘어나 칸 위치를 잘못 읽는다 — Claude 화면 넷째 칸이 (482,821) 글인데 상자는 (368,654)~ 로 나옴. 가로 위치는 `rects_from_uia`(1px 뺌)로 본다.
- **크로미움 범위의 `GetChildren` 은 빈 배열**이었다(10-29 측정 kids[] — 아이콘 칸도). 칸 안 버튼을 이걸로 알아낼 수 없다.
- **`GetEnclosingElement` 는 칸이 여러 요소에 걸치면 위쪽 그룹을 준다** — 아이콘 칸도 Button 이 아니라 group(50026).
- **whisperer 연결 시험(`tests/test_tts_engine.py`)은 함수만 AST 로 떼어 온다** — 함수가 쓰는 모듈 수준 값은 `_GLUE_VARS` 에 이름을 넣어야 한다(`tests/test_whisperer_selection.py` 는 `_FUNCS` + 변수 목록 따로).
