## 1. 작업 흐름

### 1-1. Supertonic 으로 바꿔 달라는 요청 → 거둬짐
**배경**: 10-31 Paseo 대화(Claude State Bar)가 "Google Chirp 3 HD 요금이 하루 만 원씩 나와 Paseo 를 DB 서버의 공개 모델 Supertonic 3 으로 바꿨다, 이 앱에도 넣어 달라"는 수정 요청(ab52249f)을 보냈다. 중계기가 이 대화를 열었고, 받음만 답했다(이 앱이 Electron 이 아니라 Python 이고, Supertonic 의 ogg 를 풀 단계가 새로 필요하다는 사실도 알림).
**처리**: 같은 날 저녁 "실제로 들어 보니 잡음이 심해 포기, 서버도 지움, Paseo 는 WaveNet A 로" 취소 통보(5559c361). 작업 안 함. 이 앱 영향: WaveNet-A 는 목록에 이미 있고 마크업이 자동으로 빠진다는 것만 답함.

### 1-2. 읽기 요금 브리지
**배경**: 11-01 리규형님이 Paseo 대화에서 "두 앱에도 어려움을 알리고 4달러 칸·설정 UX 를 Paseo 와 맞추고, 요금 계산 브리지를 PC 앱에 만들어 한 곳에서 세 곳 사용량을 보게, 무중단·무버튼"이라 지시(188410e0). 이 대화에서 버튼 "멈추지 않고 끝까지"로 확인받고 진행.
**처리**: 새 `tts_usage.py`(결제 달·세기·확장 기록·Paseo 파일·합계·받는 창구), `tts_engine.make_google_synthesize(on_sent=)`, 설정 창 목소리 칸을 Paseo 모양 "Zephyr · Chirp 3 HD · 100만 자 30달러 (이번 달 PC 앱 N자)"로, 목록을 Paseo 여덟 개로, "읽기 사용량" 창. 크롬 확장 대화와 넘기는 길 규격을 맞춤(423b8e9a — 그쪽이 같은 시각 51889·/v1/usage 로 제안한 6d7a0993 과 엇갈려 이쪽 규격으로 정리).
**결과**: 시험 통과, 창 캡처 한/영 확인, Paseo 에 결과 회신(188410e0 completed).

### 1-3. 사용량 알약
**배경**: 리규형님 "지금 이런 식보다 위젯 알약으로 — 트레이 아이콘을 한 번 클릭하면 선택된 모델에 몇 자 썼는지 계속 업데이트. 나가는 돈이 너무 많아 모니터링하려는 것". 버튼으로 내용(글자·무료분, 넘으면 달러)·켜고 끄기(왼쪽 클릭·유지)·거절 기록(남김)을 정하고, "끌어서 이동·자리 기억·누르면 읽기 사용량 창"을 덧붙이심.
**처리**: 새 `usage_pill.py`, 트레이 숨긴 기본 항목, 5초 주기 갱신, 설정 두 칸(usage_pill_visible·usage_pill_position), 받는 창구 거절 까닭 콘솔 한 줄.
**뒤이은 손질**: "알약 누르면 알약이 있는 모니터에 — 자꾸 다른 모니터에 뜬다" → 처음엔 모니터 가운데로 고치다가, 스크린샷 "이런 식으로"(알약 바로 위) 를 받고 알약 위 오른쪽 끝 맞춤으로 바꿈. 사용량 창 새로고침이 알약도 함께 고치게.

### 1-4. 확장 몫이 0 이던 까닭
**배경**: 리규형님이 어사이드에서 읽었는데 확장 몫이 0. 거절 기록을 넣은 뒤 30분 동안 받음·거절 둘 다 없음 → 요청 자체가 안 옴 → 확장 대화에 원인 확인 요청(bf4fc623).
**결과**: 확장 코드는 정상. 그쪽이 어사이드 기본 프로필에서 시험으로 읽히자 바로 들어옴(10자). 리규형님이 읽은 곳은 어사이드 **다른 프로필**(버튼 답) — 프로필마다 확장 저장소가 따로라 그 프로필 확장이 아직 옛 코드. 새로고침을 부탁드림. 같은 이름("Chromium")이 둘이 될 것이라 사용량 창에서 이름이 겹치면 설치 구분 글자 앞 8자를 덧붙이게 고침.

## 4. 발견한 코드베이스 함정
- **pystray 왼쪽 클릭 = 메뉴의 기본 항목.** `_win32 _on_notify` 가 WM_LBUTTONUP 에 `Menu.__call__` 을 부르고, 그것은 `self.items` 중 `default=True` 를 찾는다. `items` 는 visible 로 거르지 않아 `visible=False` 기본 항목도 불린다(실측 "hidden default ran"). 그래서 오른쪽 메뉴를 늘리지 않고 왼쪽 클릭만 따로 쓸 수 있다.
- **BaseHTTPRequestHandler.log_message 는 stderr 에 쓴다** — 창 없는 설치본(exe)은 stderr 가 없어 예외가 날 수 있다 → 덮어써서 아무것도 안 하게 했다(tts_usage.UsageReceiver).
- **ThreadingHTTPServer 기본 allow_reuse_address=True** — 윈도우의 SO_REUSEADDR 는 다른 프로세스가 같은 포트를 가로채게 둔다 → False.
- **받는 창구 알림(on_report)을 답보다 먼저 불러야** 시험(그리고 확장 쪽)이 답을 받은 순간 기록이 끝나 있다.
- **큰 본문(413)** 은 서버가 읽지 않고 답한 뒤 닫아서 보내는 쪽에서는 연결 끊김(WinError 10053)으로 끝날 수 있다 — 시험은 둘 다 거절로 받는다.
- **Tk `-alpha` 는 일반 창에는 써도 된다** — 금지는 NOACTIVATE 창(빨간 점·알약)만(Tk 가 확장 스타일을 덮어씀). 사용량 창은 투명하게 띄워 바깥 크기(winfo_rootx/y − winfo_x/y)를 잰 뒤 알약 위로 옮긴다.
- **Windows 파이썬 zoneinfo 는 tzdata 패키지 없이 America/Los_Angeles 를 못 찾는다** → `tts_usage._pacific_dst_utc` 규칙 계산.
- **Google 결제 달 경계**: 11월은 한국 11-01 16:00(그날 서머타임이 02:00 에 끝나 0시는 아직 PDT), 12월은 12-01 17:00.
- **크롬 확장은 브라우저마다·프로필마다 저장소가 따로**다. 어사이드는 브랜드에 자기 이름을 안 내서 label 이 "Chromium" — 프로필이 둘이면 이름이 겹친다.
- **확장 서비스 워커는 확장 일(읽기·오른쪽 클릭·저장소 변화)이 있어야 깬다** — 이 앱이 켜진 것만으로는 그동안 센 양이 오지 않는다.
- **개발 모드 콘솔 로그**는 저장소 바로 아래 `whisperer_console.log` 이고 실행마다 새로 쓴다 — 앞 실행의 기록은 남지 않는다.
