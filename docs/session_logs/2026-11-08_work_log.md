## 4. 발견한 코드베이스 함정

- **Paseo 합계 파일의 `total` 칸은 "Paseo 몫"으로 읽힌다.** `tts_usage.read_paseo_usage`(`tts_usage.py:343~366`)가 `v`·`month`·`updatedAt`·`total`·`sources`·`stale` 칸을 읽고, `summarize`(`tts_usage.py:373~399`)가 `total = Paseo + 이 앱 + 확장`(391줄)으로 더한다. Paseo 가 이제 이 앱·확장 몫을 읽어 더하므로, 그 세 곳 합계를 같은 `total` 칸에 쓰면 이 앱 사용량 창과 알약에서 이 앱·확장 몫이 두 번 들어간다. 답장에서 `total` 은 Paseo 몫(PC + 서버 + 직원 데몬)만 두고 세 곳 합계는 다른 칸 이름으로 넣어 달라고 부탁했다(응답 대기).
- **Paseo 합계 파일을 읽는 곳은 알약만이 아니다.** 알약 글(`whisperer.py:3193 _usage_pill_text`)과 설정 창 "읽기 사용량" 창(`whisperer.py:3035 show_usage_dialog`) 둘이다. 알약을 지워도 사용량 창을 남기면 읽기는 그대로 필요하다.
- **설치본 프로세스의 실행 경로는 일반 권한에서 안 보인다.** 관리자 권한 exe(uac_admin)라 `Get-CimInstance Win32_Process` 의 `ExecutablePath` 가 비어 나온다. 어느 판인지는 `C:\Program Files\BluemingReadAloud\BluemingReadAloud.exe` 의 시각·크기를 `dist` 와 맞춰 본다.
