## 4. 발견한 코드베이스 함정

- **Paseo 합계 파일(`~/.paseo/claude-state-bar/tts-usage-all.json`) 칸 뜻** — 최상위 `sources`·`total` = Paseo 장비 몫(키 구분 없음), `extra` = 이 앱("PC 읽기 앱")·확장("크롬 확장") 몫, `grand` = 세 곳 합계(키 구분 없음). 키별은 `keys[id] = {tail, counts, paseo, sources}` 와 `keySources[장비][id] = {tail, counts}`. `keys[id].counts` = 그 키의 세 곳 전부(이 앱·확장 포함), `keys[id].paseo` = 그 키의 Paseo 몫만, `keys[id].sources` 에는 장비 이름과 함께 "PC 읽기 앱"·"크롬 확장"도 섞여 있다. `counts` 를 Paseo 몫으로 쓰면 이 앱 몫이 두 번 더해진다
- **같은 파일의 출처 불일치(11-12 17:50 판)** — "AI_IVR_Server-Gabia 대표님"(직원 데몬으로 보임)은 `keys`·`keySources` 에만 있고 `sources`·`total`·`grand` 에는 없다. 키별 합(1,060,444)과 `grand`(1,002,379)가 58,065 다르다. Paseo 쪽에 물음(a0f0861c)
- **크롬 확장은 아직 키를 안 보낸다** — `tts-usage-extension.json` 의 `sources[].keys` 가 없어서 Paseo 는 확장 몫을 PC 의 Paseo 현재 키 쪽에 넣는다. 그래서 오늘 이 앱 키 몫의 확장 칸은 0
- **윈도우판 pystray 체크 표시** — 메뉴를 만들 때만 `checked` 를 읽는다. 켬/끔 함수가 `update_tray_menu()` 를 안 부르면 왼쪽 클릭으로 끈 뒤에도 오른쪽 메뉴 체크가 남는다(`toggle_usage_pill` 에 넣음)
- **설치본은 관리자 권한** — 일반 권한의 `Get-Process` 로는 `Path` 가 비어 나온다. 설치 폴더는 `installer/BluemingReadAloud.iss` 의 `DefaultDirName={autopf}\BluemingReadAloud` = `C:\Program Files\BluemingReadAloud`. 설치본 설정·콘솔 로그도 그 폴더 바로 아래
- **개발 모드 프로세스는 두 개** — `WindowsApps\python.exe`(바로가기)와 실제 `Python313\python.exe`. 끌 때 명령줄에 `whisperer.py` 가 있는 파이썬을 찾아 둘 다 끈다(`Get-CimInstance Win32_Process`)
- **`UsageCounter.month_counts(key=)` 의 옛 기록 처리** — 키 칸이 없으면 `_adopt_keys` 처럼 이번 달 몫을 지금 키 몫으로 본다. "이번 달"을 실제 시계로 정하면 시험이 다음 달에 깨지므로 `now` 인자를 받는다
